| D-348 | **A job, not an event, loads the packs: `mitigation/load-packs`, at start, when the module is turned on, and daily.** It reads `/opt/vedette/content/mitigation` (bounded: regular files only, no links, ≤ 1000 packs, 256 KiB each, 32 MiB in all, unexpected files refuse the directory) and calls `Loader.Install`, whose first step is the signature. No directory = a build without packs (debug log); the same or an older version = `ErrReplay`, quiet (packs of a newer image stay after a rollback of the image); a bad signature or a malformed directory fails the run (job log) and changes nothing. Module off = no job (SYS-5); packs already loaded stay. | The packs change only with a new image, which restarts core, so a start-time run is enough; the daily run only retries a failure. `core.update.applied` (the deferred plan) does not exist and would miss a first install. Not chosen: an HTTP route to upload packs (a new write path for content the maintainers must confirm). | 2026-11-12 |
