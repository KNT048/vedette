# features/inventory

Stories: S-INV-1 (device list, observations with a source + confidence, scan scope, the box's own sensor), S-INV-2 (hand declaration in ≤3 clicks from a catalogue of ~880 products: all of CISA KEV + a curated list; CSV import/export), S-INV-3 (to review: approve / mark unknown / delete, a notice when a new device appears), S-INV-4 (osquery: a token + a one-line install script for Linux and Windows Server; Wazuh: pulled over a read-only API; needs the agent-intake module).

Pages: `/devices` (two lists Devices / To review, one search box with tokens in `?q=`, `deviceQuery.ts`; the Add a device dialog at `?add=<manual|snmp|osquery|wazuh|csv>`, #849), `/devices/:id`, `/devices/setup` (admin: Scope, Sensor, SNMP, Agents; SNMP will move to Settings › Scanning in #850), Settings › Declared software (`/settings/declared-software`, products declared without a device). API: `/api/v1/inventory/…`, `/api/v1/install/*` (install scripts, public), `/api/v1/intake/*` (osquery/Wazuh report back). Assets live in the shared `assetsStore`; own tables: `inv_meta`, `inv_obs`, `inv_notify`, `inv_settings`, `sp_sensor`, `intake_agent_tokens`, `intake_wazuh`.

Decisions: the UI is English only; no multi-site; no consent text (one commitment box + an "as is" line); a network range without /prefix is refused, not guessed; no Trivy, no macOS.
Slots consumed: `device.panels` (props `{ assetId }`) on the device detail page; `device.actions` (props `{ assetId }`, the "Check this device now" button of #850) at the top of the device page; `devices.actions` (props `{ selectedIds, clearSelection }`, "Scan selected / Scan the LAN now" of #850) on the Devices list: when a module plugs in, the table gets a selection column. Provides no slot. `SnmpSection` (no props) and `CredentialDialog`/`CredentialForm` are exported for Settings › Scanning.
Conventions: an observed value is never overwritten; a manual edit adds an observation with the source "manual"; a secret (osquery token, Wazuh password) is returned in full once / only its last 4 characters.
