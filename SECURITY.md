# Reporting a vulnerability in Vedette

Vedette is a security product; a vulnerability in Vedette itself is handled as an incident.

- Report privately through the repository's GitHub Security Advisories.
- We acknowledge within 2 working days and aim to ship a fix or mitigation within 14 days for critical issues and 30 days for high ones.
- Every security fix gets an advisory (GHSA, and a CVE where appropriate), is delivered through the product-advisory update channel and is shown in the app.
- Each release ships with an SBOM (CycloneDX); dependencies are scanned daily in CI.
- There is no cash bounty. Reporters are credited if they wish.
