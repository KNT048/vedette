# Skills

The AI assistant's skills are listed in code today (`modules/ai/skills.go`); see [docs/AI_ASSISTANT.md](../docs/AI_ASSISTANT.md) §2.
This folder holds only `_template/`, the planned file format for skills that could later ship as files (compatible with the Agent
Skills format: a `SKILL.md` with front matter, schemas and fixtures). Nothing in the product reads this folder yet.
