The installer now compares the token with the machine's `enroll.secret`; when they differ (or there is none, as after `--uninstall`) it stops osqueryd and removes osquery's database (`/var/osquery/osquery.db`, Windows `C:\Program Files\osquery\osquery.db`: the old key and unsent results) before writing the new secret and restarting, so osqueryd enrols under the new token; the same token is a repair and keeps the key; `--uninstall` removes the database too. The old `node_key` is held by no machine any more: its node row stays under the old token, silent, until `node-prune` removes it after 90 days or the old token is revoked. The box does not delete it on the new enrolment: `host_identifier` is a name the client states, so a holder of one token must not be able to evict another token's machine by naming it.
