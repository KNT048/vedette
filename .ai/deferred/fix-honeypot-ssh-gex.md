  Title: SSH module: diffie-hellman-group-exchange crashes the connection (AttributeError: no attribute 'dhSecretKey'), login attempt (4002) never logged
  Body: OpenCanary 0.9.10 on Python 3.13 with Twisted 26.10.0 (the override is older than that Twisted). `HoneyPotTransport.ssh_KEX_DH_GEX_REQUEST` in `opencanary/modules/ssh.py` (line 187) overrides Twisted's method to pick the smallest group the client accepts (`getDHPrime(min)`), but it leaves out Twisted's `self._startEphemeralDH()`, which Twisted's own method calls between choosing the group and sending `MSG_KEX_DH_GEX_GROUP`. When the client then sends `MSG_KEX_DH_GEX_INIT`, Twisted's `ssh_KEX_DH_GEX_INIT` calls `_finishEphemeralDH`, which reads `self.dhSecretKey` and fails: `builtins.AttributeError: 'HoneyPotTransport' object has no attribute 'dhSecretKey'` (Unhandled Error in the twistd log, connection dropped). Only the 4000 line (new connection) is logged; the login attempt (4002) is lost. Many scanners and brute-forcers offer group exchange first. Reproduce: `ssh -o KexAlgorithms=diffie-hellman-group-exchange-sha256 -o PreferredAuthentications=password user@<canary>` → "Connection closed by <canary> port 22" after the key exchange starts, no password prompt. Suggested fix: add `self._startEphemeralDH()` after `self.g, self.p = self.factory.getDHPrime(min)` in `ssh_KEX_DH_GEX_REQUEST` (and, as a test, a group-exchange login that asserts the 4002 log line). We work around it by wrapping the method at start-up.
