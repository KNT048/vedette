Debian and Fedora accept a licence stated by the author outside a licence file and package it with the standard text while asking upstream to add the file: Fedora "Identifying licenses" lists "a statement in a README" as a valid source of licence information (https://docs.fedoraproject.org/en-US/legal/identify/); Debian Policy 12.5 requires the licence text in `debian/copyright` (https://www.debian.org/doc/debian-policy/ch-docs.html#copyright-information), which packagers fill with the standard text of the licence upstream states. Not chosen: dropping the rule for all modules (a new unlicensed dependency would ship silently); a path-only exception (a later version could change licence unseen); waiting for upstream (no channel with a known answer time, and the image would keep shipping without the texts); patching censys out of nuclei (changes the program, D-319 keeps the Go sources unmodified).
