| D-489 | **Common SMB firewalls and Linux hosts are read, not only stored (S-LOG-1, S-LOG-2, W1 "Stored only" finding).** 45 of 48 log source kinds were stored only: the bad-connection check and digest did not read their fields. New profiles (data in `modules/logs/data/profiles`): `filterlog` for pfSense and OPNsense (IPv4 filterlog CSV, pass/block, direction `in` on the LAN side), `sophos` (SFOS key="value": log_type Firewall and Content Filtering, `src_ip`, `dst_ip`, `domain`, status Deny/Drop = blocked), `cisco-asa` (302013/302015 "Built outbound", 106023 and 106100 deny/permit; inbound and teardown are not read), `sonicwall` (id=firewall, m=98 "Connection Opened"; drops are not read, their message ids are not documented well enough to trust), `paloalto` (TRAFFIC CSV, PAN-OS 10/11 field order: src field 8, dst 9, action 31; allow vs deny/drop/reset/block-url), `iptables` (kernel LOG lines with the UFW or EdgeOS/UniFi rule-set prefix `[NAME-n-A|D|R]`, for ubiquiti, linux-rsyslog and linux-journald; a custom `--log-prefix` is not read because whether the packet was dropped is not known). Two small engine additions, both data-driven: `conn_patterns` (anchored whole-line readers with a `blocked` flag; the "exactly one `->`" guard of `conn_pattern` is MikroTik-specific) and `apps` (a profile reads only lines of the listed syslog programs: filterlog, kernel). Anti-framing: every pattern starts with `^`, every field before the addresses is a strict class that excludes the comma, text the user wrote (URL, user name, rule or ACL name, User-Agent) comes after the addresses or inside quotes the kv reader treats as one value; lines of another program, text in front of the record, a second record inside a field, inbound or reversed direction, private destinations and IPv6 make no connection (`TestFirewallProfilesInjection`, `TestFirewallProfilesRefuse`). A Linux host keeps the D-487 failed-login path: sshd lines are not read by the profile (`apps`), so the generic remote reader still finds the address (`TestLinuxKindsKeepTheirLoginLines`). Not done: Draytek, Zyxel, WatchGuard (formats not documented well enough or not cheap), UniFi switches/APs (controller logs, not firewall), IPv6, ASA inbound, SonicWall and Cisco FTD denies.
