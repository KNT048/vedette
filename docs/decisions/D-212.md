| D-212 | **The arguments of a connection read tool are the model's words: they pass the hooks and the personal-data mask, and under the privacy rule only connections inside the network are offered (ai, WP-25 slice 5a, S-AI-5, D-93 (5), D-127).** (1) Every call's arguments are written out once as canonical JSON (a `\u` escape cannot hide a word from a pattern), then go through the built-in personal-data hook (emails and phone numbers masked, ID numbers block) and the `before_tool` hooks, before anything is read or sent. The mask is pattern-based: an address split across values or percent-encoded is not recognised, so "masked" is a best effort, not a guarantee. What is shown in the answer, kept in the history and written to the activity row (with its hash) is the masked text; a blocked or held call is stored as `[withheld by hook <name>]`. Calls that did not run store `[not run]`. (2) While `internal_only` is on, a connection tool is offered only if its connection's address is a literal private, loopback, unique-local or CGNAT IP (the test of INV-3 for profiles, `provider.IsInternalAddr`). A host name is not trusted (it can resolve to a public address later), and when the addresses cannot be read (`Config.ConnTargets`, core's connection list) nothing is offered: fail closed. The rule is checked again at call time, so a rule turned on after the tools were listed refuses the call (the connection's address is read when the tools are listed; a connection moved to a public address mid-question needs a new Test, because moving the host clears its pin). `core/conn/read` offers no address metadata, so the box reads it from `core/conn` List in `cmd/vedette`. (3) PRIVACY.md flows 3 and 12 and their Settings text say that the AI writes these arguments, that they can contain data it saw from the box, and that they go to that connection, which may be at a public address. (4) The schema shown to the model for a connection tool keeps only an allow-list of keywords (type, properties, required, items, enum, bounds, additionalProperties, anyOf/oneOf/allOf); free text, `pattern` and `x-*` extensions are dropped. | The same model-in-the-loop exposure exists wherever a model fills tool arguments that go to a third-party server.
