| D-208 | **feeds: a pull never connects to the box itself.** (1) Every feeds pull (custom and built-in; built-ins use public https, so nothing changes for them) refuses at connect time loopback (127.0.0.0/8, ::1: in the shipped container loopback is Vedette itself) and the box's own host addresses (the /32 and /128 entries: the container's interfaces plus what vedette-host reports through the same `notifyBoxAddrs` source as notify), never the interface subnets, because the user's LAN lives there and internal feeds such as MISP legitimately do. The check runs on the resolved address before `connect` (the dialer connects to that literal and the socket Control hook repeats it, so DNS rebinding is covered), every redirect hop goes through the same dialer (redirects are already same-host only), and no proxy is used. Same rule as notify D-86 (2). (2) Box addresses unknown (vedette-host has not answered since start): notify fails closed for everything, but a feeds pull must not stop the built-in KEV/EPSS on every cold start, so while unknown a pull may connect only to a global unicast address (no RFC 1918, loopback, link-local, CGNAT 100.64/10, ULA, or other special ranges, checked on the embedded IPv4 of transition forms too): built-in public feeds keep working, custom LAN feeds wait. A pull refused only for that reason (`ErrBoxAddrsUnknown`) is not recorded as a failure, gets no back-off and shows no error; the feed stays due for the next tick, and one debug line is logged. Accepted risk: a box that has a public address of its own could be reached over https during that window; a self-hosted appliance is normally on a LAN. (2b) The check also looks at the IPv4 inside NAT64 (64:ff9b::/96, 64:ff9b:1::/48), 6to4 (2002::/16) and IPv4-compatible (::a.b.c.d) addresses, and the container default gateway counts as the box (same set as core/conn). (2c) A refused address shows "Vedette does not pull feeds from itself or from loopback, link-local or cloud metadata addresses." (3) Feed values in row errors were already quoted and cut to 40 UTF-16 units; now unprintable runes (controls, bidi overrides) become spaces instead of escapes, so a snippet is short and plain; the destination rule is the real fix for reading internal endpoints. API error codes and messages do not change.
