# features/scan

Modules `scan` and `scan-credentialed`. Stories: S-SCAN-1 (a confirmation scan, choose targets inside the scope), S-SCAN-2 (rescan by itself when a new KEV with a template appears, on/off + an event log), S-SCAN-3 (the result and evidence of each scan, linked back to the finding), S-SCAN-4 (a time window, speed, exclusions, auto-stop, "Stop now", a schedule, a probe log kept ≥90 days), S-SCAN-5 (a credentialed SSH scan).

- Own tables: `scan_config`; the scope and the commitment box are read from inventory (`scope_confirmed_at`), external targets from exposure (the box's IP, seen by the box in the last 30 days; domains by DNS TXT), `scan_runs`, `scan_probes`, `scan_events`, `scc_target`.
- The mock computes progress by the clock (`timing.stepMs` per device, `timing.stopMs` for "Stop now"); the UI polls every 5 seconds while a scan runs (every second while stopping). `a-cam03` is a sample device that does not answer, to illustrate auto-stop.
- An SSH key is not stored or returned; only the last 4 characters are kept.
- Slots provided/consumed: none. #850: there is no menu entry; the history, the probe log and Nuclei's own settings (schedule, rescan, auto-stop) are tabs and cards of Settings › Scanning (`features/scanning`). The old `/scans…` forwards (`ScansMoved.tsx`): `?run=` → the page of that run (`/runs/<id>`), `?target=<device>` → the check page of that device with "Check this device now", `?target=ext:<id>` → External exposure.
- External targets (exposure) are listed but this build does not scan them (`reason: not_supported`, 400 `out_of_scope`); when built, `POST /scans/runs` asks exposure's `CheckScannable` (INV-13, 409 `ip_not_current`) right before scanning. A hand-declared device is never scanned (`declared_by_hand`, INV-5 of inventory); picking a device by hand is consent for that device (fragile: a quarter of the speed).
- The scanner of the `scan` container is not ready: `can_scan=false` with `block_reason`, `POST /scans/runs` returns 503 `scanner_unavailable` (`scannerStore` for tests). A probe in flight when "Stop now" is clicked records `stopped`. The CSV blocks spreadsheet formulas (device names come from the network).
- A fragile, unclassified or hand-declared device carries `pick_only`: the page never pre-ticks it (default, "Select all", "Only devices with findings", `?target=`), the user must tick it to select it; the row says "Fragile: pick it to scan at a quarter of the speed".
- `zoneStore` (whether the organisation's time zone can be read) for `schedule_blocked_reason` and `next_run: null`; `engineStore.busyUntil` (the scanner is still busy after "Stop now", `timing.engineMs`) for `engine_busy` of `GET /scans/runs` and 409 `already_running`; a rescan event dropped after 7 days is `expired_no_template|expired_scanner|expired_zone`.
