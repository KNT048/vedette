| D-601 | **Per-device sources, and SNMP's own scope (kien 2026-11-17, FortiGate added by hand; amends INV-5 / `declared_by_hand` of D-84 and the lan_ranges bound of D-512 for SNMP).** (1) Each active source of the box is on or off **per device**: `inv_asset.scan_source` (the network scan: discovery's nmap and the vulnerability scans) and `snmp_source` (SNMP reads), set by an administrator on the device's Sources card (`PUT /inventory/devices/{id}/sources`, audited per source: who, device, source, on/off). Default: on for a device a sensor found (the box's own settings decide, as before), **off for a device added by hand**: it gets no packet until a person turns a source on, and turning one on lifts `declared_by_hand` for that source only. (2) **Off stops that traffic for any device**, discovered ones too: scan off is refused as `regular_scan_never` everywhere (discovery, the sweep's protected list, Scan now, scheduled and picked vulnerability scans), SNMP off as `snmp_off`; the run in progress on the device stops; what the source found stays and manual values still win. (3) An agent (osquery, Wazuh) has no switch: it is installed or uninstalled on the machine. Both are pushed or pulled without probing the device (osquery POSTs to `/intake/osquery/*`, `modules/agent-intake/service.go` `Enroll`, `ingest.go` `Log`; Wazuh is pulled from its manager's API, `wazuh.go` `pull`), so the LAN scope never applied to them. (4) **SNMP is bound by the exclusions and each credential's own "Send only to" list, not by lan_ranges**: the person who typed an address into a credential administers that device; lan_ranges keep governing discovery and nmap only. Every other rule holds: exclusions always win ("never touched, not even with SNMP", reason `excluded`), local addresses only (`core/localnet`: RFC 1918 and RFC 6598 100.64/10, checked when the credential is saved and again at dispatch, so a public address can never be listed or sent to), approved devices only, never the box or its decoys, one read-only GET of fixed OIDs, the rate, the window for the scheduled round, scanning on and the scope commitment, the probe log.
