(2) Only when core runs with `-host-socket=""` (`HostCards` ok=false) the box's cards are those of the passive sensor's last heartbeat **younger than 90 s**, the same rule as `online` (`onlineWithin`); no such heartbeat → the batch is not applied (503 `store_busy`), never filtered by the core container's cards (on the bridge it sees only its own link, so the real host cards were not excluded and the box could appear as a device of its own network). (3) `SetInterface` without a host accepts only a heartbeat younger than 90 s; an older one is "not reported in the last 90 seconds" (`bad_interface`), so an offline sensor's stale list cannot be chosen from. (4) `netHost.Interfaces` in `cmd/vedette` no longer reads the operating system's interfaces (`osInterfaces` removed); it is `HostCards` for `Service.Run`, which production never starts (D-141).
