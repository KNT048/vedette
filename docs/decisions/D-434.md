| D-434 | **The Sources page shows the box's certificate for syslog over TLS: SHA-256 fingerprint, subject, expiry, self-signed or not, and a PEM download (S-LOG-1; closes the deferred line of `feat-logs-syslog-tls.md`).** Problem: a device that sends syslog over TLS (FortiGate and others) has to trust the box's certificate, and a self-signed box certificate is trusted by nobody until the admin exports it and adds it to the device; the page said nothing. Decision: `GET /logs/sources` carries `box.tls` = `{ fingerprint_sha256, subject, not_after, self_signed, pem }` (null/absent when the box serves no TLS, i.e. when `tls_unavailable` applies). The service asks the same `GetCertificate` a handshake would (so a renewed certificate shows at once, D-139) and reads only the leaf: the PEM is public data, so no new route is needed and the GUI builds the download from it in the browser (no new outgoing flow, nothing to PRIVACY.md). Self-signed = issuer equals subject; for a certificate another authority issued the card says the device must trust that authority. The card sits under the sources table with the fingerprint, and the device setup dialog of a TLS source points to it. Not done: a CA bundle or chain download (the leaf is what a pinning device needs and what a self-signed box has), and the port is not repeated in the card (the source row already shows it). | Fortinet documents that the FortiGate verifies the syslog server's certificate against a CA certificate imported on the device during the TLS handshake and that a client certificate is only needed when the server requires one (FortiOS "send syslog over TLS" community tips: https://community.fortinet.com/t5/FortiGate/Technical-Tip-Send-Syslog-over-TLS-to-a-rsyslog-server/ta-p/248101 and https://community.fortinet.com/t5/FortiGate/Technical-Tip-How-to-send-encrypted-logs-to-Syslog-server/ta-p/240995), so the admin must be able to fetch the box certificate; syslog-ng's default network source uses 6514 for TLS and the receiver's certificate is what the senders trust (https://syslog-ng.github.io/admin-guide/060_Sources/005_Default-network-drivers/000_Default-network-drivers_options). D-214 (the TLS listener), D-139 (renewal). | 2026-11-13 |
