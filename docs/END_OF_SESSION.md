# Kết thúc session (khi kien nói "doc")

0. Đọc `.ai/deferred/<session>.md` đầy đủ; mỗi dòng: Done / Moved (ghi nơi) / Dropped (có OK kien). Hết dòng → xoá file.
1. `.ai/tasks/current.md`: đang ở đâu, kế tiếp, chưa quyết.
2. `docs/project-map/completion-log.md`: entry mới, mới nhất trước, có **đo** (lệnh chạy, kết quả), nói rõ chưa làm/chưa xác minh.
3. `docs/DECISIONS.md`: quyết định mới, có lý do; đo số cao nhất trước khi thêm.
4. `docs/USER_STORIES.md`: cập nhật trạng thái xác minh nếu có.
5. `docs/project-map/lessons.md`: nếu kien sửa gì.
6. Kiểm tra `CLAUDE.md` còn đúng (lệnh, file map). Không dán changelog vào CLAUDE.md.
7. Build output đã dọn. Commit trên nhánh; không push main; không tag.
