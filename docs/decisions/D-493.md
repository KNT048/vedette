The gate is unchanged and still answers synchronously with today's errors (not verified, expired, TXT missing, commitment, `ip_not_current`, 409 `busy`, 429 `rate_limited`, 501, 409 `module_off`). When it passes, the answer is **202 `ScanRun {id, target_id, target_value, by, started_at, finished_at, status, phase, snapshot_id, error}`** and the scan runs in a goroutine the Service owns (context of the Service, not of the request; the runner's 5-minute cap stays). `GET /exposure/scan` returns the run that runs now or the last one (`status` running/done/failed/stopped, `error {code, message}` with the same codes and texts as before, `snapshot_id` when done; `null` before the first run); `POST /exposure/scan/stop` (operator) cancels it (nothing saved, 409 `not_running` when none runs).
