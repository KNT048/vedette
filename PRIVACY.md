# Privacy — what Vedette sends out, and how to turn it off

Vedette runs on your own machine. Your devices, logs, findings and AI keys **never leave it**. Below is the **complete** list of data that goes out to the Internet. The same list is shown in the app under Settings → Privacy.

| # | Flow | What is sent | Where to | Can you turn it off? |
|---|---|---|---|---|
| 1 | Feed pulls (D-36) | The box fetches each feed **directly from its source**, with plain HTTPS requests for public files. None of your data is sent; only your IP address appears in the source's logs. Sources: CISA KEV (`www.cisa.gov`; if that address answers 403, an error or nothing in time, CISA's own GitHub mirror of the same file, `raw.githubusercontent.com/cisagov/kev-data`, D-91), FIRST EPSS (`api.first.org`), the affected versions of the exploited CVEs from the NVD (`services.nvd.nist.gov`, CVE API 2.0 `?hasKev`, about 18 requests of 100 CVEs on the first day, retried with a pause when NVD is busy, then only the CVEs NVD changed since the last pull; each request carries only the fixed parameters `hasKev` and `resultsPerPage`, the record number it starts at (`startIndex`) and, after the first day, the date window of the change (`lastModStartDate`, `lastModEndDate`), with the same `User-Agent: Vedette/<version>` as every feed pull, D-500), the nuclei-templates CVE list, IPsum and hagezi TIF (public data files on `raw.githubusercontent.com`), ET Open (`rules.emergingthreats.net`), abuse.ch Feodo Tracker (`feodotracker.abuse.ch`), the Tor exit list (`check.torproject.org`), and any **custom feed you add** in Settings → Feeds. **Bug report (D-42) is not a flow.** The box sends nothing when you report a problem. The form builds a filtered diagnostic file (version, module states, recent errors; no devices, logs, findings, keys, emails or IPs) that you download, and "Open GitHub issue" opens GitHub in **your own browser** with your text filled in. You decide what to post. Nothing leaves the box unless you do it.

Cookies: only the three that signing in needs, all first-party and never sent anywhere but your box: the session cookie (`__Host-vedette_session`), its anti-forgery companion (`__Host-vedette_csrf`) and a trusted-device cookie (`__Secure-vedette_device`, D-77) that keeps someone else's failed guesses from locking you out. No tracking, no analytics, no third-party fonts or scripts.

Export or delete all your data: Settings → Data.
