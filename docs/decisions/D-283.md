| D-283 | **CVE news answer: box-labelled lines, box-made sources.** The model fills a closed schema `{exploited, public_exploit, workaround, other[≤3]}`; the box writes the labels ("Exploited:", "Public exploit code:", "Workaround:"), so every answer says the three things S-AI-3 asks for, in order. The task tells the model that a repository naming a CVE may be a scanner, a fake or malware, to say "appears", and never to tell the reader to run code from it. Sources and citations are made by the box only: the NVD page, the fetched vendor page, the GitHub search page and the feed posts' own links on the feed's host (another host falls back to the feed address); the NVD row carries NVD's required notice ("This product uses the NVD API but is not endorsed or certified by the NVD."). | NVD terms of use https://nvd.nist.gov/developers/terms-of-use ; the study of malicious CVE proof-of-concept repositories on GitHub (Leiden University, 2022) https://arxiv.org/abs/2210.08374.
