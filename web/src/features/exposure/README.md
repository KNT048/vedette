# features/exposure

Story: S-EXP-1 (domain or public IPs the box finds itself → prove ownership → commitment checkbox → list subdomains, IPs, open ports, exposed admin interfaces, expiring certificates; daily snapshots and comparing two days).
LEGAL §3 rule: no scan unless ownership is verified, and the commitment ("my company owns this and I am authorized to scan it", with who and when) is recorded. The "Scan now" button is locked with a reason, and the API returns 409 `not_verified` / `expired` / `txt_missing`, or 400 `commitment_required`, if called directly.
Ownership: a domain = DNS TXT record `vedette-verify=<token>`, re-checked right before every scan (missing = blocked). A public IP = only an IP this box itself uses to reach the Internet; no endpoint takes an IP as input (typing one is 400 `ip_not_allowed`). Private, reserved and CGNAT results are refused (400 `not_public`); verification attempts by people are limited to 10 per hour; everything is audited.
Public IPs, auto-detect (kien 2026-11-09): the section "Public IPs of this box" has an auto-detect switch (on by default), a check interval (1 min to 24 h, default 60 min, only shown while auto-detect is on), "Detect now" and the IP list with last seen, expiry and Remove. The box asks three public "what is my IP" services (checkip.amazonaws.com, icanhazip.com, api.ipify.org) over several rounds of new connections at first start and then every interval, accepts an IP only when at least two agree in a round, and adds or renews every IP that passed (several IPs behind a load balancer are all found). An IP is valid for 30 days after the box last saw it (`verified_at` = last seen, `expires_at` = +30 days, `validity` expiring at 5 days or less); it expires only when the box has not seen it for 30 days. Turning auto-detect off keeps the list. A removed IP comes back if the box keeps using it while auto-detect is on. API: `GET /exposure/targets` carries `box_ip {auto, interval_min, last_run}`; `PUT /exposure/box-ip/settings`; `POST /exposure/box-ip/verify` ("Detect now", `{items, message}`); remove = `DELETE /exposure/targets/{id}`.
Mock tables: `exp_targets`, `exp_snapshots`, `exp_commitments`, `exp_attempts`, `exp_settings`. DNS simulation: the first TXT check of a new domain says "not found", from the second it is found. The mock runs the automatic check when `GET /exposure/targets` finds it due (no timer). Box egress simulation: localStorage `vedette-mock-egress` is a comma separated list of the public IPs the box currently leaves through (default `203.0.113.10,203.0.113.11`, a load balancer), , `offline` when no service answers, or `disagree` when they never agree.
For the scan module: `exposureTargetsStore` (kind, value, verified_at, expires_at), `exposureSnapshotsStore`, `exposureCommitmentsStore`; or `GET /api/v1/exposure/targets` and use only `scannable` targets.
Roles: add/delete target, auto-detect settings, Detect now, commitment = admin; re-check ownership, scan now = operator; view = viewer.
Slots: none provided, none consumed.
