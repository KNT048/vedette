Anti-framing: every pattern starts with `^`, every field before the addresses is a strict class that excludes the comma, text the user wrote (URL, user name, rule or ACL name, User-Agent) comes after the addresses or inside quotes the kv reader treats as one value; lines of another program, text in front of the record, a second record inside a field, inbound or reversed direction, private destinations and IPv6 make no connection (`TestFirewallProfilesInjection`, `TestFirewallProfilesRefuse`).
