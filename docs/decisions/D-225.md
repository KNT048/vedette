| D-225 | **"Ask your data" suggests memories through one trailing `Remember:` line, not a tool and not a schema (S-AI-7, INV-8, INV-14).** (1) **How**: while `suggest_enabled` is on, the task of `ask-my-data` adds one sentence: when the tool results show a lasting fact about this network that would help later answers, end the answer with one line `Remember: <one short sentence>`, at most one, never a person's name, a password, a key or an address of a threat feed. The box looks only at the last non-empty line (any case; `**`, `-` or `*` around the word allowed, as models write it), takes it out of the answer before it splits the paragraphs (an answer that is only that line keeps the fact as its text; a `Remember:` line elsewhere is advice and stays), and hands it to `SuggestMemory` with the evidence `asked "<question as sent>" and read <tools>` (at most 200 characters, invisible characters dropped; the question after the before_ai hooks, so a masked question stays masked), in a context that outlives the request, after the answer is stored. Only a question that called at least one tool suggests: the fact must come from the box's data, not from the asker's word, and the evidence names the tools so the administrator sees where it came from (a tool result is untrusted text that could carry a planted fact; the approval, INV-8, is the guard). A memory setting that cannot be read does not stop the question; it suggests nothing. Off → the sentence is not in the task and a `Remember:` line is left in the answer as text (the model was not asked, so it is not a suggestion). An answer an after_ai hook stops suggests nothing. Not kept (too many waiting, a text a hook stops, already remembered or rejected in 30 days) → never an error of the question. (2) **Shown**: `AskResult.memories_suggested` counts the suggestions kept by this question (0 when the history is read back), and the answer says "The AI suggested 1 memory about this network. Nothing is remembered until an administrator accepts it." with the link "Review in Settings, AI assistant, Memory" for an administrator (as the log digest, walk 2026-11-12; an operator, who cannot open that page, sees the sentence without the link). (3) **Why not a tool**: a `suggest_memory` tool would be the first tool with a write in the ask loop; INV-14 keeps the loop read-only, and a tool call costs one more turn. **Why not a schema**: the ask loop sends no schema (D-223 (4)), and turning the answer into JSON would change every answer for a field most answers leave empty. A plain trailing line costs a few tokens and degrades to nothing when the model ignores it. **Why one**: one question is one topic; the digest, which reads a whole day, keeps two.
